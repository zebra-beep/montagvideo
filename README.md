# Мультфильмы

## Old Farmer — Busy Little Farm

Горизонтальный мультфильм: 1920 × 1080, 16:9, 30 кадров/с, 3 минуты 2 секунды.

- [Скачать исправленную версию 2 — Remotion CRF 16](https://media.githubusercontent.com/media/zebra-beep/montagvideo/main/Old_Farmer_v2_CR16.mp4)
- [Английские субтитры SRT](https://github.com/zebra-beep/montagvideo/raw/refs/heads/main/Old_Farmer_subtitles.srt)

Версия 2: заметнее природный фон и голоса животных. Громкость песни сохранена на уровне версии 1, автоматического приглушения песни нет. Дополнительно очищена периодически появляющаяся полупрозрачная четырёхлучевая звёздочка в сборных исходниках; остальные пиксели этих исходников вне небольшой области восстановления сохранены без изменений.

Дополнительные отдельные записи животных: Chickens demanding food (alys, public domain), Sheep bleat (CC0), peaceful sound of a herd of cows in the Swiss Alps (Florian Reichelt, CC0), через Wikimedia Commons. Запись [Pig grunt — Erdie](https://commons.wikimedia.org/wiki/File:Pig_grunt_-_Erdie.ogg), автор erdie, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/): выбраны короткие фрагменты, отрегулированы уровни и края, запись включена в фон.

38 отобранных фрагментов смонтированы по фактически исполненной песне Busy Little Farm. Вся песня сохранена целиком; к ней тихо добавлены птицы, вечерние сверчки и звуки животных из предоставленных сцен. Английские субтитры сверены с исполнением, включая повторы припева.

Квадратные сцены вписаны в 16:9 с мягким фоном по бокам, чтобы сохранить героев в кадре. Рекламные концовки ZSky и неудачные планы исключены, угловые знаки CapCut AI и Dreamina очищены. Исходники разного разрешения: в том числе Full HD, 720p и квадратные; увеличение не создаёт новых деталей.

Экспорт через Remotion: PNG-кадры, H.264 CRF 16, preset slow, без ограничения битрейта видео; AAC 320 кбит/с. Подготовленные сцены перекодированы без потерь при CRF 0, чтобы не добавлять промежуточное сжатие с потерями. CRF 16 — финальное сжатие с небольшими потерями высокого качества, а не математически без потерь. Видео хранится через Git LFS; для скачивания устанавливать Git LFS не требуется.

Природный фон: [Google Sound Library](https://developers.google.com/assistant/tools/sound-library/animals), june_songbirds и afternoon_crickets_long. Основная песня, видео и звуки животных предоставлены пользователем.

## Jungle Train — путешествие по джунглям

Готовый мультфильм: 2 минуты, широкоформатный 1280 × 720, 24 кадра/с.

### Версия 2 — новые сцены, Remotion CRF 16

- [Скачать версию 2 высокого качества — около 110 МБ](https://media.githubusercontent.com/media/zebra-beep/montagvideo/main/Jungle_Train_v2.mp4)
- [Английские субтитры SRT](https://github.com/zebra-beep/montagvideo/raw/refs/heads/main/Jungle_Train_v2_subtitles.srt)

Пересобрано с перегенерированными фрагментами пользователя. Старые планы 608 × 352 заменены подходящими более чёткими исходниками; все выбранные файлы не меньше 1248 × 704. Сохранены моменты смены сцен и английские субтитры. Полная одобренная аудиодорожка перенесена без повторного кодирования. Логотипы очищены локально, рекламные концовки вырезаны, увеличение спящих персонажей уменьшено для сохранения деталей.

Экспорт: Remotion, PNG-кадры, H.264 CRF 16, preset slow, без ограничения битрейта. CRF 16 означает высокое качество со сжатием с небольшими потерями. Основной файл хранится через Git LFS, поскольку превышает лимит обычного Git. Прямая ссылка скачивания выдаёт готовый MP4; устанавливать Git LFS для скачивания не требуется.

Добавлены цветные английские субтитры по тексту пользователя, стук колёс, свисток, птицы, вода и тихий ночной фон. Логотипы Digen, Happy Horse и Pippit очищены.
